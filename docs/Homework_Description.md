# C++大作业内容：
### 1.从 https://github.com/Rosmarinus-Young/vision-tracker 中将项目 clone 到本地

### 2.切出 develop 分支，在 develop 分支中按照 README.md 的要求，完成代码的编写

### 3.按照规范提交 commit,并将代码提交到自己的仓库中

### 4.完成全部代码编写后，用 markdown 编写报告并用其覆盖原来的 README.md 文件，并将 develop 分支合并回 main 分支，之后带着自己的仓库链接找学学长验收

### 5.请自行上网查阅 markdown 文件（即 .md 文件）的预览与编写方式

### 6.对于大作业的任何疑问，可以填写到问题收集表中

### 7.大作业的截止时间为11月15日
